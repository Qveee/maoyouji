# 宠物栏示例3「青铜浮雕风」设计说明

## 背景

`prototype/宠物栏示例3-Q版卡通风.html` 当前以暖木、羊皮纸和较可爱的宠物形象呈现。用户不希望继续 Q 版卡通方向，并在四个视觉方向中选择了「A · 青铜浮雕」。

## 目标

- 将页面视觉从暖木/Q 版可爱转为厚重的老 MMO「深木 + 青铜浮雕」。
- 保留现有 DNF 式纸娃娃布局、12 个装备位、穿卸装备、背包选择、Tooltip、属性计算和窗口拖动。
- 继续使用单文件 HTML + CSS + 原生 JavaScript，不引入外部依赖。

## 非目标

- 不调整宠物成长、装备属性、稀有度规则等玩法数据。
- 不重做信息架构，不新增功能。
- 暂不修改文件名，避免用户给出的原型路径失效。

## 视觉口径

### 色彩

- 主底：深木色 `#17110A` 到 `#251C13`。
- 结构线：青铜色 `#7D5F30`，内层暗线接近 `#4A3618`。
- 强调色：暗金 `#E5C778`，用于标题、经验条和关键数值。
- 正文：暖米色 `#D9C698`，次级文字用 `#A58F61`。
- 稀有度保留灰、绿、蓝、紫、橙五档，但整体降低饱和，避免彩色光效破坏复古厚重感。

### 形体

- 窗口和装备格使用近直角，圆角控制在 2-6px。
- 窗口使用外青铜线、内暗线的双层描边，配合外部投影和内高光。
- 标题栏为金属横条，带上下高光和暗影，保留可拖动交互。
- 装备格为内凹槽：深底、内阴影、青铜描边；空格使用低对比虚线。
- 经验、生命、法力条使用窄边框和轻微内阴影，避免现代大圆角胶囊感。

### 字体

- 标题继续使用黑体，正文继续使用宋体，数字继续使用 Verdana。
- 只调整颜色、字重和字距，不更换字体体系。

### 宠物立绘

- 将当前天使波利的 Q 版形象替换为更沉稳的橘猫立绘。
- 立绘使用深色描边、低饱和毛色和少量暗金轮廓光，减少圆眼和果冻感。
- 宠物基础资料同步显示为「大橘为重 / 橘猫」，与立绘一致。

## 实施范围

仅修改：

- `prototype/宠物栏示例3-Q版卡通风.html`

不改设计权威文档、清单和其他原型页。

## 验收标准

1. 浏览器打开页面无控制台错误。
2. 1400×832 视口下主体完整显示，不出现横向溢出。
3. 十二个装备位悬停、菜单、背包选择、穿卸和卸下均可用。
4. 装备稀有度边框和 Tooltip 显示正常。
5. 生命、法力、经验条与属性数值渲染正常。
6. 标题栏拖动、关闭与重新打开按钮正常。
