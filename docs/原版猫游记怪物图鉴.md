# 原版猫游记怪物图鉴（游戏内实拍采集）

> **采集方式**：通过"黑猫"客户端（江南.exe，91 服，角色 klay011）登录游戏，单击场景怪物列表中的怪物名弹出怪物卡（名称/等级/类型标签/说明/图片），截图识读文字；怪物原始 GIF 从 IE 缓存抽取（`tools/enum_cache.py` 可枚举 URL→本地文件），也可按 URL 规律直接从 CDN 下载（如 `preschool/mogu1.gif`）。
> **图片 URL 规律**：`http://s92.pet.imop.com/img/npc/<拼音>.gif`（部分有子目录，如 `preschool/`、`yunmengze/`）。**已实测**：点开怪物卡会触发该怪 GIF 下载落盘 IE 缓存（首次才会出现新条目）；内部文件名可能与中文名无字面关联（例：泡泡 = `BoLi.gif`）。
> **图片存档**：`assets/原版参考/怪物/<地图名>/<缓存原拼音名>.gif`（原文件完整拷贝，禁止对外使用）。
> **类型标签**：怪物卡括号内三段式 = 职业（战士…）/ 种族（动物、昆虫、植物…）/ 定位（物防、辅助…）；部分怪只有两段。
> **等级口径**：同格同种怪的等级逐只随机（实测草原蝎同屏 Lv.4 与 Lv.5），表格记实测值，均落在《猫游记怪物血量大全.xlsx》的等级区间内。
> 采集进行中，逐图追加。表格「图片」列 = 已存档 GIF 文件名；**粗体** = 与其他怪共用同一张图。
