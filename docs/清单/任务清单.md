# 《喵游记》任务清单

> 来源：`docs/游戏规则设计.md` v1.2。本清单只整理任务，不修改源文档。  
> 统计口径：共 **73** 条任务；其中 **8 条**为源文档明确给出“任务名/类型/目标”的提取条目，**65 条**为按地图、怪物、经济与成长数值体系补全的设计条目。所有任务的对话与奖励均在本清单中落到可执行粒度。  
> 标记说明：备注含 **◆补全** 的条目为源文档未直接列出、由本清单依据规则文档补全；未标记的 8 条为源文档直接提取骨架。

## 数值与覆盖原则

- 主线覆盖：猫之城 → 新手草原 → 月牙森林 → 幽暗洞穴 → 霜雪山脉 → 烈焰火山 → 海雾群岛 → 古代遗迹 → 虚空魔窟 → 击败梦魇之影 → 传说猫侠加冕。
- 奖励经验按 `升级经验 = floor(100 × 当前等级^1.5)` 控制，单条任务通常提供对应等级 15%~35% 的升级经验，BOSS 关键节点可到 40%~50%。
- 金币按每日主动探索约 20,000、8 小时打工约 16,000~24,000 的产出基准折算，任务奖励低于日常探索总收入。
- 文档已有怪物、掉落与道具优先复用：田鼠、蛛丝、毒囊、冰晶、火之精华、古代齿轮、进化石、星辉石、技能书、藏宝图残页等。
- NPC 覆盖：猫之城中心设施具名 NPC、各城镇至少 1 名专属支线 NPC、野外 NPC、日常/周常/成就入口均已覆盖。
