## 0. 属性与成长口径

### 0.1 六维属性

| 属性 | 中文名 | 主要影响 |
|---|---|---|
| VIT | 体力 | 生命上限、物理防御 |
| STR | 力量 | 物理攻击 |
| AGI | 敏捷 | 速度、命中、闪避 |
| INT | 智力 | 魔法攻击、法力上限 |
| SPR | 精神 | 魔法防御、治疗效果 |
| LUK | 幸运 | 暴击、掉宝率、金币加成 |

### 0.2 初始属性与升级

- 1 级所有品种基础六维：`VIT 5 / STR 5 / AGI 5 / INT 5 / SPR 5 / LUK 5`，再叠加品种初始加成。
- 升级所需经验：`EXP(需) = floor(100 × 当前等级^1.5)`。
- 每次升级：
  1. 品种主属性自动 `+1`；
  2. 获得 `2` 点自由属性点；
  3. 回复满 HP / MP。
- 自由加点不锁职业，任何品种都能通过加点、装备、技能走向任意流派。

### 0.3 派生属性公式

| 派生属性 | 公式 | 上限 |
|---|---|---|
| 生命 HP | `50 + VIT×8 + 等级×10 + 装备HP` | — |
| 法力 MP | `30 + INT×5 + 等级×5 + 装备MP` | — |
| 物理攻击 | `STR×2 + 装备物攻` | — |
| 魔法攻击 | `INT×2 + 装备魔攻` | — |
| 物理防御 | `VIT×1.2 + 装备物防` | — |
| 魔法防御 | `SPR×1.2 + 装备魔防` | — |
| 速度 | `AGI×2 + 装备速度` | — |
| 命中率 | `75 + AGI×0.5 + LUK×0.3` | 95% |
| 闪避率 | `AGI×0.4 + LUK×0.2` | 40% |
| 暴击率 | `5 + LUK×0.5` | 60% |
| 暴击伤害 | `150 + LUK×1` | 300% |

## 3. 宠物主动技能总表

源：5.7「示例技能表（12 个）」，并全文检索其他章节补充。除下列 12 个具名技能外，源文档其他章节只出现技能分类、升级公式、状态说明或战斗提示，没有新增宠物可用主动技名称，因此不虚构额外主动技。

### 3.1 技能升级通用规则

- 技能等级上限 = 角色等级。
- 升级消耗：同名技能书 `×技能等级` + 金币 `×(技能等级×500)`。
- 每升 1 级：
  - 伤害 / 治疗倍率 `+8%`（相对基础值）；
  - 状态触发概率 `+2%`。
- 公式：`升级后倍率 = 基础倍率 × (1 + 8% × (技能等级 - 1))`。

## 4. 宠物被动技能总表

源文档仅给出规则「被动技：常驻属性加成，占被动栏」和示例「力量强化 +8%」，未给出完整被动表。以下按六维属性、第2章派生属性和既有战斗公式补全一套可实装的基础被动池。除「力量强化 +8%」直接来自原文示例外，其余均为「◆补全」。

### 4.1 被动技能通用规则

- 被动技能栏固定 `3` 格；下表每条被动均占用 `1` 格。
- 被动为常驻面板加成，需装备入被动栏后生效；卸下即失效。
- 同名被动不叠加；同类百分比加成建议相加后一次性结算，避免多乘区膨胀。
- 六维属性百分比先计入六维面板，再按第2章公式计算派生属性。
- 命中、闪避、暴击为「百分点」加成，最终仍受第2章上限约束。
- 伤害减免、治疗加成、掉宝率、金币加成按独立修正项进入对应公式。

### 6.6 面板修正合成公式

```text
战斗全属性修正 = 饱食系数 × 疲劳系数 × 忠诚系数

饱食系数：<30 → 0.90；否则 1.00
疲劳系数：≥80 → 0.85；否则 1.00
忠诚系数：≥80 → 1.05；否则 1.00
```

- 饱食 `<30` 且疲劳 `≥80`：`0.90 × 0.85 = 0.765`，即全属性最低降到 `76.5%`。
- 若同时忠诚 `≥80`：`0.90 × 0.85 × 1.05 = 0.80325`，即约 `80.325%`。
- 心情不直接影响全属性，只影响战斗经验与打工效率。
