# 《喵游记》技能清单（双职业版）

> 依据：`D:\maoyouji\docs\游戏规则设计.md` 第 5 章「技能系统」。本清单只整理主动技能，不修改源文档。

## 技能通用规则

### 元素与克制

```text
火 → 风 → 地 → 水 → 火（五行环，单向克制）
光 ↔ 暗（互相克制）
```

| 关系 | 伤害系数 |
|---|---:|
| 攻击方克制防守方 | ×1.3 |
| 攻击方被防守方克制 | ×0.75 |
| 无克制关系 / 无属性 | ×1.0 |

### 状态效果

| 状态 | 效果 | 持续 | 结算方式 |
|---|---|---|---|
| 中毒 | 每回合损失最大 HP 3% | 3 回合 | 回合开始 |
| 灼烧 | 每回合损失施放者物攻×40% | 2 回合 | 回合开始 |
| 冰冻 | 无法行动；受火伤 +50% | 1 回合 | 回合结束解除 |
| 眩晕 | 无法行动 | 1 回合 | 回合结束解除 |
| 睡眠 | 无法行动；受击伤害 +30% 并醒来 | 1~2 回合 | 受击解除 |
| 护盾 | 吸收固定伤害值 | 3 回合 | 先于 HP 扣除 |
| 破甲 | 物防 -20% | 3 回合 | 属性面板 |
| 减速 | 速度 -25% | 2 回合 | 行动序重算 |
| 攻击 UP/DOWN | 攻击 ±20% | 3 回合 | 属性面板 |

同名状态不叠加，重复施加刷新持续时间；互斥状态（冰冻与灼烧）后者覆盖前者。

> 补全技能中的「闪避 UP」「速度 UP」「吸血」「恐惧」「驱散」为流派特色机制，实现时需在状态或技能特效字段中扩展；其余状态均沿用源文档。

### 学习、升级与技能栏

- **技能等级上限** = 角色等级。
- **升级消耗**：同名技能书 ×技能等级 + 金币 ×（技能等级×500）。
- **每升 1 级**：伤害倍率相对基础值 **+8%**；状态触发概率 +2%。
- **主动技能栏**：2~4 格，随进化阶段解锁；被动技能栏 3 格。
- **目标说明**：单体 = 单个敌方目标；全体 = 敌方 1~3 只分别结算；自身 = 施法猫咪本身。
- **标记说明**：
  - 「文档映射」：来自源文档 5.7 示例技能，数值保持不变。
  - 「◆补全」：按源文档数值梯度与本清单流派定位补全。
