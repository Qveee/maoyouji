## 1.3 属性点规则

1. 装备收益以 **六维属性点 VIT / STR / AGI / INT / SPR / LUK** 为主；品质表中的「属性点数量」只统计六维点数。
2. 六维按源文档 2.2 派生：
   - `HP = 50 + VIT×8 + 等级×10 + 装备HP`
   - `MP = 30 + INT×5 + 等级×5 + 装备MP`
   - 物攻 = `STR×2 + 装备物攻`；魔攻 = `INT×2 + 装备魔攻`
   - 物防 = `VIT×1.2 + 装备物防`；魔防 = `SPR×1.2 + 装备魔防`
   - 速度 = `AGI×2 + 装备速度`
3. 词条可辅以少量派生属性：HP、MP、物攻、魔攻、物防、魔防、速度、命中、闪避、暴击、格挡、元素强化等。
4. 战士系装备倾向：STR / VIT / 物防 / HP / 速度；魔法师系装备倾向：INT / SPR / 魔攻 / MP / 命中。
5. 旧版直接物攻/物防数值迁移时，按上述公式折算为属性点；旧数值保留在备注中，便于对照。

## 1.4 强化与镶嵌速查

| 系统 | 规则 |
|---|---|
| 强化等级 | +0 ~ +15；每级主属性 +10%（相对装备基础值） |
| 成功率 | +1~+3：100%；+4~+6：80%；+7~+9：60%；+10~+12：50%；+13~+15：40% |
| 失败保护 | 失败不掉级；连续失败 3 次后下次必成 |
| 高强化材料 | +10 起额外消耗「星辉石」（任意 BOSS 掉落） |
| 孔位 | 每件 0~2 孔，随机生成；可用「打孔锥」开 1 孔 |
| 宝石 | 攻击、防御、生命、速度、暴击 5 种；1~5 级；3 颗同级合成 1 颗高一级 |
| 强化范围 | 强化只放大装备主属性，不放大特效触发概率、套装效果与宝石数值 |
