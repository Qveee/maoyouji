# 《喵游记》网页游戏 · 完整规则设计文档

> **版本**：v1.5　|　**类型**：多人在线回合制宠物养成 RPG　|　**平台**：网页（H5 / 响应式）
> **设计原则**：规则简洁可读、数值公式透明、便于前端直接实现、无强联网要求（可先做单机版）
> **v1.1 修订**：明确「宠物 = 玩家角色本身」。玩家领养并扮演一只小猫，无捕捉宠物系统；新增饱食度 / 心情 / 疲劳 / 忠诚度 / 打工等经典猫游记式养成玩法。
> **v1.2 修订**：地图改为自由网格探索（**取消行动力**）；怪物在格子上可见，名称带「攻击」标识，点击可查看详情并主动开战；新增**多城市 NPC**（装备店/道具店/中心城等）与**野外 NPC** 任务派发体系。
> **v1.3 修订**：新增第 13 章**界面布局设计**——定义六大功能区（地图 / 记录 / 怪物列表 / 玩家列表 / 世界聊天公告 / 频道聊天）、玩家交互按钮（聊天 / 跟随 / 组队 / 交易 / 攻击）与图标样式规范；游戏定位升级为**多人在线**网页游戏。
> **v1.4 修订**：地图格子改版——**小尺寸方块、编号乱序、不规则分布（含空地）、视野迷雾（走动才见新格子）、怪物隐藏随机刷**（抵达格子才知道有什么怪）；新增 **13.6 AI NPC**：接入 GLM 大模型（默认 `glm-5.3-flash`）的智能 NPC「猫仙人」。
> **v1.5 修订**：**移除饱食度、心情值、AI 猫仙人**三个系统（简化养成线）；地图增加**镜头视野**（世界大于视口，视野外格子存在，随移动切换）；新增**战斗页面**（攻击时切换到回合制战斗界面）；技能栏改为 **5 列翻页**。

## 1. 游戏概述

### 1.1 核心概念

游戏开始时，玩家在猫之城领养站**领养一只小猫，这只猫就是玩家在游戏中的唯一角色**。玩家为它起名、送它上学学技能、带它探索地图、打怪升级、穿装备，一路成长为传说中的「猫侠」，最终击败虚空魔窟深处的「梦魇之影」。

> 本设计遵循经典猫游记的核心设定：**没有捕捉宠物、没有宠物栏、没有助战宠物**。战场上出战的就是你的猫本身；所有养成系统（属性、装备、技能、状态）都作用在这只猫身上。

### 1.2 核心玩法循环

```
睡觉恢复疲劳 → 探索地图 → 抵达格子随机遇怪
        ↑                        ↓
      忠诚度提升         获得经验/金币/掉落
        ↑                        ↓
     打工挂机收益 ← 提升战力 ← 升级/学技能/换装备
                                 ↓
                          解锁新地图
```

### 1.3 核心系统一览

| 系统 | 作用 | 关键词 |
|---|---|---|
| 宠物养成 | 角色即宠物，日常照顾 | 领养、品种、疲劳、忠诚 |
| 属性成长 | 战力基础 | 六维属性、等级、进化 |
| 地图系统 | 探索与冒险舞台 | 网格地图、城市与NPC、精英/BOSS |
| 技能系统 | 战斗策略核心 | 元素克制、状态效果、猫咪学校 |
| 战斗系统 | 核心玩法 | 回合制、速度行动序 |
| 道具与经济 | 养成资源流转 | 喂食道具、装备、打工、商店 |

## 2. 角色（宠物猫）属性系统

> 本章属性均属于宠物猫本身。宠物与怪物战斗时直接使用这些面板数值。

### 2.1 基础六维属性

| 属性 | 中文名 | 主要影响 |
|---|---|---|
| VIT | 体力 | 生命上限、物理防御 |
| STR | 力量 | 物理攻击 |
| AGI | 敏捷 | 速度、命中、闪避 |
| INT | 智力 | 魔法攻击、法力上限 |
| SPR | 精神 | 魔法防御、治疗效果 |
| LUK | 幸运 | 暴击、掉宝率、金币加成 |

### 2.2 派生属性公式

| 派生属性 | 计算公式 | 上限 |
|---|---|---|
| 生命 HP | `50 + 体力×8 + 等级×10 + 装备HP` | — |
| 法力 MP | `30 + 智力×5 + 等级×5 + 装备MP` | — |
| 物理攻击 | `力量×2 + 装备物攻` | — |
| 魔法攻击 | `智力×2 + 装备魔攻` | — |
| 物理防御 | `体力×1.2 + 装备物防` | — |
| 魔法防御 | `精神×1.2 + 装备魔防` | — |
| 速度 | `敏捷×2 + 装备速度` | — |
| 命中率 % | `75 + 敏捷×0.5 + 幸运×0.3` | 95 |
| 闪避率 % | `敏捷×0.4 + 幸运×0.2` | 40 |
| 暴击率 % | `5 + 幸运×0.5` | 60 |
| 暴击伤害 % | `150 + 幸运×1`（即 1.5 倍起步） | 300 |

### 2.3 升级规则

- 升级所需经验：`EXP(需) = floor(100 × 当前等级^1.5)`
- 每次升级获得：
  1. **品种主属性自动 +1**（见 3.2 品种表）；
  2. **2 点自由属性点**（玩家手动分配，可在主城「洗点喵师」处洗点）；
  3. 回复满 HP / MP。
- 初始属性（1 级，所有品种）：体力 5 / 力量 5 / 敏捷 5 / 智力 5 / 精神 5 / 幸运 5，再叠加品种加成。

| 等级 | 累计所需经验参考 |
|---|---|
| 10 | ≈ 5,200 |
| 20 | ≈ 26,100 |
| 30 | ≈ 74,300 |
| 40 | ≈ 158,000 |
| 50 | ≈ 290,000 |

## 3. 宠物养成系统

### 3.1 核心理念

- 宠物就是角色本身：**一只猫，一条成长线**。
- 成长包含两条线：
  - **战斗成长**：等级、属性点、装备、技能、进化；
  - **日常养成**：疲劳、忠诚度——控制冒险节奏，保持良好状态。

### 3.2 领养与品种

开局在领养站从 6 个品种中选择一只（相当于职业出身），可自定义名字与毛色（纯外观）：

| 品种 | 定位 | 初始加成 | 主属性（升级自动+1） | 品种天赋（出生自带） |
|---|---|---|---|---|
| 狸花猫 | 物理输出 | 力量 +3 | 力量 | 「野性直觉」物理技能伤害 +8% |
| 暹罗猫 | 魔法输出 | 智力 +3 | 智力 | 「魔力亲和」魔法技能伤害 +8% |
| 布偶猫 | 治疗辅助 | 精神 +3 | 精神 | 「温柔之心」治疗效果 +15% |
| 橘猫 | 坦克 | 体力 +3 | 体力 | 「厚实皮毛」受到伤害 -8% |
| 黑猫 | 敏捷暴击 | 敏捷 +3 | 敏捷 | 「夜行者」暴击率 +5%、速度 +5% |
| 三花猫 | 幸运均衡 | 幸运 +3 | 幸运 | 「好运喵」掉宝率 +10%、金币 +10% |

> 品种不锁死玩法：自由加点 + 技能自由学习，任何品种都能走任意流派；品种只提供初始倾向与一个不可替换的天赋。

### 3.3 成长阶段（进化）

| 阶段 | 达成条件 | 外观 | 效果 |
|---|---|---|---|
| 幼猫 | 出生 | 小体型 | 主动技能栏 2 格 |
| 少年猫 | Lv 10 自动进化 | 中体型 | 主动技能栏 3 格，全属性成长 +5% |
| 成年猫 | Lv 30 + 进化石×2 + 5,000 金币 | 大体型 | 主动技能栏 4 格，全属性成长再 +5% |
| 猫侠 | Lv 50 + 进化石×5 + 击败炎魔库拉 | 披风造型 | 解锁第 2 天赋栏，全属性成长再 +5% |
| 传说猫侠 | Lv 60 + 击败梦魇之影 | 金光特效 | 称号 + 全属性 +5%，终局形态 |

> 「全属性成长 +5%」指升级所得属性点（含自动 +1 与自由点）按 1.05 / 1.10 / 1.15 / 1.20 倍结算。

### 3.4 疲劳值（0~100）

> v1.5 起**饱食度与心情值已移除**，日常养成仅保留疲劳与忠诚（3.5 节）两条线，简化照顾成本、聚焦探索战斗。

| 规则 | 数值 |
|---|---|
| 每场战斗 | +3 |
| 每移动 10 格 | +5 |
| ≥80 | **全属性 -15%**，提示"你的猫累了" |
| 睡觉（主城猫窝/营地） | 每小时 -30 |
| 离线自动恢复 | 每小时 -15 |

> 疲劳是**无行动力设计下的节奏阀**：连续战斗/赶路会累积，过高时回城镇旅馆睡觉恢复。

### 3.5 忠诚度（0~100）

| 事件 | 变化 |
|---|---|
| 抚摸（每日 1 次交互） | +5 |
| 战斗胜利 | +1 |
| 战斗失败 | -10 |

效果：
```
忠诚度 ≥ 80 → 全属性 +5%，解锁天赋「同生共死」（见 5.5）
忠诚度 < 30 → 战斗中每回合 10% 概率"闹脾气"跳过行动
```

### 3.6 打工系统（放置收益）

- **解锁**：Lv 5，在猫之城打工板接取；单次最长 8 小时，可随时提前结束。

| 岗位 | 每小时收益 | 备注 |
|---|---|---|
| 鱼摊帮工 | 金币 2,000 + 随机鱼类材料 | — |
| 外卖飞猫 | 金币 3,000 | — |
| 图书馆管理员 | 金币 1,200 + 技能书碎片×1 | — |
| 矿洞零工 | 金币 1,800 + 随机矿石 | 疲劳 +5/小时 |

```
实际收益 = 基础收益 × (1 + 等级 × 1%)
```

> 定位：打工是**保底收入**，收益约为主动探索的 50%，避免挂机完全替代游玩。

### 3.7 洗点与外观

- 主城「洗点喵师」：重置自由属性点，费用 `等级 × 200` 金币。
- 外观工坊：毛色 / 配饰 / 披风（进化阶段解锁），纯外观不影响数值，可花钻石购买。

## 4. 地图系统

### 4.1 世界结构（多城市网络）

```
猫之城（中心城：领养站/猫咪学校/打工板/猫窝/仓库/洗点喵师/外观工坊/大商店/任务板）
 ├─ 新手草原（Lv 1~10）──── 草原小镇
 ├─ 月牙森林（Lv 10~20）── 月牙村
 ├─ 幽暗洞穴（Lv 20~30）── 矿工营地
 ├─ 霜雪山脉（Lv 30~40）── 温泉客栈
 ├─ 烈焰火山（Lv 40~50）── 火山哨所
 ├─ [隐藏] 海雾群岛（Lv 35~45）── 渔港小镇
 ├─ [隐藏] 古代遗迹（Lv 45~55）── 学者营地
 └─ [终局] 虚空魔窟（Lv 50~60）── 恢复泉水（无城镇）
```

- 世界由多张网格地图组成，**每张地图至少连接一座城镇/据点**；猫之城是中心枢纽。
- 城镇是独立的安全区小地图（无怪物、无疲劳消耗）。
- **快速传送**：抵达过的城市之间可免费互相传送（地图菜单中选择）。

### 4.2 地图网格机制（无行动力）

- **移动完全免费**：不消耗任何行动力/体力，玩家每次只能走一格（上下左右四方向）。
- **格子规格**：小尺寸方块（约 50px），每张地图的格子**编号乱序分配**（同图不重复，如 00-95 打乱），布局**不规则**——存在无法通行的空地/障碍，整体不构成整齐的方形矩阵。
- **视野与迷雾**：地图世界远大于显示区域，玩家只能看到身边一定范围（切比雪夫距离 ≤4）的格子；**走动时视野跟随移动**，不同格子随之进入/离开画面，鼓励探索。
- **镜头视野（经典节点版）**：节点图样例以"镜头窗口"实现视野——视口外的节点**同样存在**，玩家移动时镜头平滑跟随、视野随之切换。
- **怪物隐藏（随机性）**：格子上**不显示怪物**；玩家抵达格子时才随机生成该格怪物——约 50% 概率无怪，有怪时为 1~3 只（种类按本图怪物池加权随机，等级 ±1 浮动）。**玩家事先不知道格子里有什么**。
- **怪物刷新**：某格子怪物被全部击败后，一段时间（正式版 3 分钟 / 样例 8 秒）后该格**重新随机生成**怪物（再次随机，与上次无关）。
- **尸体标记**：怪物被击败后，**尸体显示在怪物列表中**（灰色字体「XX的尸体」，无攻击按钮），**保留 1 分钟后自动清除**；同格多只怪物的尸体依次排列。
- **主动战斗**：怪物不会主动索敌，战斗全部由玩家在怪物列表中点击「攻击」发起。
- **格子附加元素**（按概率生成，全部可见、点击交互）：

| 元素 | 概率 | 说明 |
|---|---|---|
| 宝箱 | 10% | 点击开启，金币/道具；10% 概率是宝箱怪（触发战斗） |
| 采集点 | 10% | 草药/矿石/鱼点，点击采集，每日刷新 |
| 可疑草丛 | 8% | 可选择翻找：60% 获得道具，40% 扣 10% HP |
| 野外 NPC | 5% | 派发任务的野外 NPC（见 4.5） |

- **地图解锁**：角色等级达标 + 击败前一张地图 BOSS；隐藏地图需特殊道具（藏宝图残页×3 等）。
- **节奏控制**：取消行动力后，游玩节奏由**疲劳值**（3.4 节）自然调节——疲劳过高时回城镇旅馆睡觉。

**地图生成参数表**（正式版可按地图调参）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 世界尺寸 | 16 × 12 格 | 单张地图的格子坐标系大小 |
| 空地率 | 22% | 随机不可通行格子占比（不规则观感来源） |
| 连通性校验 | 必须 | 从出生点 BFS，不可达格子改为空地，保证全图可达 |
| 格子抖动 | ±5px | 每格随机位置偏移，打破整齐方阵感 |
| 编号分配 | 乱序不重复 | 可走格子洗牌后分配 00 起始的两位编号 |
| 视野半径 | 4（切比雪夫距离） | 仅渲染视野内格子，视野边缘半透明雾化 |
| 城镇格子 | 1 个（远离出生点） | 安全区，无怪物 |
| BOSS 格子 | 1 个（距出生点最远） | 抵达时触发 BOSS 现身播报 |

**随机刷怪参数表**：

| 参数 | 默认值 |
|---|---|
| 无怪概率 | 50% |
| 有怪数量 | 1~3 只 |
| 种类池 | 本图怪物表加权随机（普通怪为主，精英较少） |
| 等级浮动 | 30% 概率 +1 级 |
| 判定时机 | 首次抵达该格时生成，并播报发现信息 |
| 重新随机 | 该格怪物全灭后 3 分钟（样例 8 秒）重新随机生成 |

### 4.3 怪物交互（点击查看 → 主动攻击）

- **怪物名称后的「攻击」标识**是战斗入口（位于怪物列表中）；地图格子上不显示怪物，抵达格子后怪物才会出现在列表里。
- 点击怪物本体 → 弹出**怪物详情面板**：

| 面板内容 | 说明 |
|---|---|
| 名称 / 等级 / 类型 | 普通（白）/ 精英（金）/ BOSS（红） |
| 元素属性 | 元素图标 + 克制提示（例：「火系 · 被水克制」） |
| 面板属性 | HP / 物攻 / 魔攻 / 物防 / 魔防 / 速度 |
| 技能列表 | 该怪物可使用的技能与效果 |
| 掉落预览 | 可能掉落的道具与基础掉率 |
| 推荐等级 | 低于推荐等级 5 级以上时红字警告 |
| 「攻击」按钮 | 确认后进入战斗；精英/BOSS 需二次确认 |

- 等级差距超过 15 级时按钮旁显示「危险」提示，但不禁止挑战（自由度优先）。

### 4.4 城市与 NPC

每座城镇充满各种功能 NPC，负责交易、服务与**派发任务**：

| NPC / 设施 | 功能 | 分布 |
|---|---|---|
| 中心城设施 | 领养站、猫咪学校、打工板、猫窝、仓库、洗点喵师、外观工坊 | 仅猫之城 |
| 装备店 | 购买/出售武器与防具；偶有限量高级货 | 所有城镇 |
| 道具店 | 食物、玩具、战斗消耗品 | 所有城镇 |
| 铁匠铺 | 装备强化、打孔、宝石镶嵌 | 猫之城 + 各区域主城 |
| 餐厅 | 花金币用餐，恢复 HP/MP 与少量疲劳 | 所有城镇 |
| 旅馆 | 睡觉恢复疲劳与 HP/MP（每小时疲劳 -30） | 所有城镇 |

### 4.7 精英怪与 BOSS 规则

- **精英怪**：全属性 ×1.5，经验 ×2，掉落率 ×2，名称显示金色。
- **BOSS**：
  - 全属性 ×3，HP 额外 ×2；
  - 多阶段技能（HP 每下降 33% 切换技能组）；
  - 必掉 1 件 A 级以上装备 + 30% 概率掉 1 颗进化石；
  - 不可逃跑。

```

```
地图系数：普通怪 1.0 / 精英 2.0 / BOSS 3.0。三花猫天赋「好运喵」另 +10%。每种掉落独立判定，从掉落表自上而下。

### 5.1 技能分类

| 类型 | 说明 | 例子 |

## 6. 战斗系统

### 6.1 基本结构

- 战斗形式：**回合制**。出战单位为你的宠物猫（1 名）vs 敌方（1~3 只怪物）。
- 战斗呈现：点击「攻击」后**战斗画面覆盖整个地图区域**——玩家与怪物**形象登场**（左右对立、名牌 + HP 条、出招冲刺/受击闪白/伤害飘字/阵亡倒下动画）。**战斗为自动进行**：进入后玩家与怪物自动互相攻击；**技能只能通过底部技能栏释放**（战斗中点击技能格，下一击释放该技能 ×1.7），战斗画面本身不放置任何攻击按钮。**战斗记录与结算均显示在左下角记录区**（不弹框），结算播报后战斗画面自动收起。
- 触发方式：点击格子上的怪物「攻击」主动发起；精英/BOSS 战斗需二次确认。

### 6.2 回合流程

```
回合开始
  ├─ 1. 结算 DOT（中毒/灼烧）与回合型状态
  ├─ 2. 按速度从高到低排序（同速随机）
  ├─ 3. 每个单位依次选择行动：
  │      攻击 / 技能 / 道具 / 防御 / 逃跑
  └─ 4. 回合结束：状态持续 -1，速度序重算
循环直到一方全灭或逃跑成功
```

### 6.3 行动选项规则

| 行动 | 说明 |
|---|---|
| 攻击 | 普通攻击（无 MP，100% 倍率） |
| 技能 | 释放主动技，消耗 MP，进入冷却 |
| 道具 | 使用背包中的战斗消耗品（每回合限 1 次） |
| 防御 | 本回合受到伤害 -50%，回复 5% MP |
| 逃跑 | 成功率 = 50% + (己方速度 - 敌方平均速度) × 1%，上限 90%；BOSS 战不可逃 |

> 敌方 2~3 只时建议搭配群体技能（如落石滚滚）或控制技能（催眠、冰冻）逐个击破。

### 6.4 战斗结算

- **胜利**：经验、金币、掉落按 4.5 节公式结算。
- **失败**：不扣经验，损失 10% 金币，回城复活（HP 50%），忠诚 -10。
- **经验惩罚**：怪物等级低于角色 10 级以上时，经验 ×0.3。

## 7. 伤害计算（核心公式）

> 攻守双方均使用第 2 章面板属性；宠物侧面板受疲劳/忠诚修正（见 3.4、3.5）。

### 7.1 判定顺序

```
选择目标 → 命中判定 → （命中后）暴击判定 → 计算基础伤害
 → 防御减免 → 元素克制 → 暴击系数 → 其他修正乘区 → 伤害浮动
 → 护盾吸收 → 扣除 HP
```

### 7.2 命中与闪避

```
实际命中率% = clamp(攻击方命中率 - 防守方闪避率, 30, 95)
```

命中判定：`rand(1,100) ≤ 实际命中率` → 命中，否则 MISS。

### 7.3 物理伤害

```
基础伤害   = 物理攻击 × 技能倍率
防御减免率 = 物防 / (物防 + 300 + 攻击方等级 × 15)      ← 上限 80%
伤害①    = 基础伤害 × (1 - 防御减免率)
```

### 7.4 魔法伤害

```
基础伤害   = 魔法攻击 × 技能倍率
防御减免率 = 魔防 / (魔防 + 250 + 攻击方等级 × 12)      ← 上限 80%
伤害①    = 基础伤害 × (1 - 防御减免率)
```

> 采用「除法减伤」：防御收益递减，不会出现完全免伤，也避免数值爆炸。

### 7.5 暴击

```
暴击判定：rand(1,100) ≤ 暴击率
暴击系数 = 暴击伤害倍率（默认 1.5，见 2.2）
```

### 7.6 元素克制系数

克制 ×1.3，被克 ×0.75，无关系 ×1.0（见 5.2）。

### 7.7 最终伤害公式（总公式）

```
最终伤害 = max(1, floor(
    攻击 × 技能倍率          ← 基础
  × (1 - 防御减免率)         ← 防御
  × 暴击系数(若暴击)          ← 暴击
  × 元素克制系数              ← 克制
  × 防御姿态(0.5, 若目标防御)  ← 行为修正
  × 技能特效(如无视防御×1.25)  ← 特效乘区
  × rand(0.9 ~ 1.1)          ← 随机浮动 ±10%
))
```

规则：
- 最终伤害下限为 **1**（永远至少造成 1 点伤害）。
- 单次伤害不超过目标「当前 HP + 当前护盾」总量。
- 猫咪侧承受伤害时，天赋（如「厚实皮毛」-8%）作为一个独立乘区计入。

### 7.8 治疗公式

```
治疗量 = floor( (魔法攻击 × 技能倍率 + 固定值) × rand(0.95~1.05) × (1 + 治疗加成%) )
```

治疗不受暴击和防御影响；治疗溢出部分浪费。布偶猫天赋「温柔之心」计入治疗加成。

### 7.9 持续伤害（DOT）

```
中毒：每回合 floor(目标最大HP × 3%)，无视防御与护盾减免
灼烧：每回合 floor(施放者物攻 × 40%)，受目标火抗修正
```

### 7.10 护盾规则

- 护盾值在创建时按公式一次性计算（如 20% 最大 HP）。
- 受击时**先扣护盾、再扣 HP**；护盾存在期间 DOT 仍直接扣 HP（毒穿盾）。
- 护盾不叠加，新护盾覆盖旧护盾（取较大值）。

### 7.11 完整演算示例

**场景**：20 级狸花猫（物攻 120，命中 88%，暴击率 15%，暴击伤害 160%）使用 3 级「猫爪击」（倍率 120%+8%×2=136%）攻击 20 级月牙狼（物防 45，HP 320，闪避 12%）。

| 步骤 | 计算 | 结果 |
|---|---|---|
| 1. 命中 | 88 - 12 = 76% | 76% 命中 |
| 2. 基础伤害 | 120 × 1.36 | 163.2 |
| 3. 防御减免 | 45/(45+300+20×15) = 45/645 | 6.98% |
| 4. 减免后 | 163.2 × 0.9302 | 151.8 |
| 5. 暴击（假设触发） | ×1.6 | 242.9 |
| 6. 元素（无属性） | ×1.0 | 不变 |
| 7. 浮动（假设 1.05） | ×1.05 | 255.0 |
| 8. 最终 | floor | **255** |

**期望伤害**（用于平衡）：
```
E[伤害] = 命中率 × (1 + 暴击率×(暴伤-1)) × 平均面板伤害
        = 0.76 × (1 + 0.15×0.6) × 151.8
        ≈ 125.4
击杀 320 HP 狼 ≈ 2.6 回合 → 3 回合内击杀，符合"普通怪 2~4 回合"的设计目标。
```

### 7.12 平衡基准（TTK：击杀所需回合）

| 目标类型 | 期望击杀回合 |
|---|---|
| 普通怪 | 2~4 回合 |
| 精英怪 | 4~6 回合 |
| BOSS | 8~15 回合（含阶段） |

若实测偏差 >30%，优先调整怪物 HP 模板系数（11 章），不动玩家侧公式。

## 11. 怪物数值模板

程序按等级自动生成怪物属性，无需逐个手配：

```
普通怪（等级 Lv）：
  HP   = floor((60 + 12×Lv) × 血量系数)
  物攻 = 10 + 3×Lv
  魔攻 = 10 + 3×Lv
  物防 = 5 + 1.5×Lv
  魔防 = 5 + 1.5×Lv
  速度 = 8 + 0.8×Lv
  EXP  = 20 + 6×Lv
  金币 = 10 + 4×Lv
```

| 定位 | 血量系数 | 攻击修正 | 说明 |
|---|---|---|---|
| 输出型 | 0.8 | ×1.2 | 高攻低血 |
| 平衡型 | 1.0 | ×1.0 | 标准 |
| 坦克型 | 1.6 | ×0.8 | 高血低攻 |
| 精英 | 全属性 ×1.5 | — | 4.4 节 |
| BOSS | 全属性 ×3，HP 再 ×2 | — | 4.4 节 |

**验算**（20 级平衡型怪）：HP = 300，物攻 = 70，物防 = 35 → 与 7.11 示例匹配，3 回合左右击杀。✔

## 12. 公式速查总表

| # | 公式 |
|---|---|
| 1 | 升级经验 = `100 × Lv^1.5` |
| 2 | HP = `50 + 体力×8 + Lv×10 + 装备` |
| 3 | MP = `30 + 智力×5 + Lv×5 + 装备` |
| 4 | 命中率 = `75 + 敏捷×0.5 + 幸运×0.3`（≤95） |
| 5 | 闪避率 = `敏捷×0.4 + 幸运×0.2`（≤40） |
| 6 | 暴击率 = `5 + 幸运×0.5`（≤60）；暴伤 = `150 + 幸运`（%） |
| 7 | 疲劳累积：每场战斗 +3；每移动 10 格 +5；睡觉 -30/小时；离线 -15/小时 |
| 8 | 状态修正：疲劳≥80 属性×0.85；忠诚≥80 属性×1.05 |
| 9 | 打工收益 = `基础 × (1 + Lv×1%)` |
| 10 | 实际命中率 = `clamp(命中-闪避, 30, 95)` |
| 11 | 物理减免率 = `物防/(物防+300+Lv攻×15)`（≤80%） |
| 12 | 魔法减免率 = `魔防/(魔防+250+Lv攻×12)`（≤80%） |
| 13 | 最终伤害 = `floor(攻×倍率×(1-减免)×暴击×元素×修正×rand(0.9,1.1))`，下限 1 |
| 14 | 治疗 = `floor((魔攻×倍率+固定)×rand(0.95,1.05)×(1+治疗加成))` |
| 15 | 中毒 DOT = `最大HP×3%`；灼烧 DOT = `施放者物攻×40%` |
| 16 | 掉率 = `基础掉率 × (1+幸运×0.2%) × 地图系数` |
| 17 | 怪物 HP = `(60+12×Lv)×系数`；物攻 = `10+3×Lv`；物防 = `5+1.5×Lv` |
| 18 | 逃跑率 = `50% + (己方速度-敌方平均速度)×1%`（≤90%） |
| 19 | 技能升级倍率 = `基础倍率 × (1 + 8%×(技能等级-1))` |

> 顶部另设通栏状态条：角色名/等级、HP/MP/经验条、金币。对应样例实现见 `prototype/猫游记界面UI.html`（经典版主样例）。

### 13.2 各区域功能规则

| 区域 | 内容与交互 |
|---|---|
| ① 地图区域（左上） | 世界地图大于显示区域，带背景图；**小尺寸方块格子、编号乱序、不规则分布**；视野迷雾——只显示玩家身边的格子，走动时镜头跟随、新格子不断进入视野；点击相邻格子移动（每次一格）；怪物不在格子上显示，抵达后随机出现 |
| ② 怪物列表（中上） | **当前抵达格子随机生成的怪物清单**；**名称后有「攻击」按钮（红色小剑图标）**；点击怪物名称弹出详情面板（4.3 节）；怪物全灭后格子重新随机刷怪 |
| ③ 世界聊天与公告（右上） | 两个页签：**世界聊天**（全服发言）与**世界公告**（系统/GM 消息，黄色高亮置顶） |
| ④ 战斗与走动记录（左下） | 实时滚动两类信息：**战斗记录**（伤害/暴击/掉落/胜负）与**其他玩家走动记录**（"XX 离开了月牙森林"）；保留最近 200 条，可清屏 |
| ⑤ 玩家列表（中下） | 同地图在线玩家清单；**点击玩家姓名查看玩家信息**（等级/品种/称号/装备摘要）；每个姓名旁有 5 个操作按钮：**聊天、跟随、组队、交易、攻击** |
| ⑥ 频道聊天（右下） | 四个频道页签：**私人**（1v1 私聊）/ **队伍**（组队成员）/ **公会**（公会成员）/ **区域**（同地图玩家）；底部输入框发送 |

### 13.3 按钮样式规范

| 按钮 | 图标 | 颜色 | 样式说明 |
|---|---|---|---|
| 攻击 | 红色小剑 | #E5484D | 小剑图标按钮，悬停加亮 + 提示"攻击"；怪物与玩家列表通用 |
| 跟随 | 小脚印（爪印） | #D98324 | 爪印图标，点击开始/取消跟随 |
| 组队 | 双人剪影 | #3B82F6 | 队伍图标，点击发送组队邀请 |
| 交易 | 金币 | #F5A524 | 金币图标，点击发起交易请求 |
| 聊天 | 对话气泡 | #22C55E | 气泡图标，点击打开与该玩家的私聊 |

### 13.4 玩家交互按钮行为

| 按钮 | 行为定义 |
|---|---|
| 聊天 | 切换右下频道到「私人」，打开与目标玩家的私聊会话 |
| 跟随 | 自动跟随目标玩家移动（同图内）；再次点击或移动取消 |
| 组队 | 发送组队邀请；对方确认后成队，队伍上限 3 猫；队长点击怪物的「攻击」全队进入战斗 |
| 交易 | 发起交易请求；双方放入道具/金币，双方确认后交换（城市内限定） |
| 攻击（对玩家） | 发起切磋（PVP）：需对方接受，或在 PVP 区域直接开战；胜负只影响称号积分，不掉落道具 |

### 13.5 多人系统说明

本章引入的聊天 / 组队 / 公会 / 交易 / 玩家 PVP 属于**多人在线系统**，采用"界面先行、后端渐进"策略：
- v1.5（当前版）：单机可玩 + 界面联调 + 战斗页面；
- v1.6：接入 WebSocket，实现聊天频道、走动记录、玩家列表实时同步；
- v1.7：组队战斗同步、交易系统、公会系统。
